- Heuristic authentication analytics and stable finding fingerprints
- FastAPI endpoints, identity-focused dashboard, and CLI JSON export
- Security headers, sanitized errors, tests, Docker, and immutable-action CI
- Architecture, schema, rules, ATT&CK, privacy, validation, and security documentation
