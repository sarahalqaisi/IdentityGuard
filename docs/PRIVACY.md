# Privacy

IdentityGuard ships with deterministic synthetic identities and authentication events. Names, organizations, public documentation IP ranges, locations, accounts, and activity are fictional demonstration data. No identity-provider connection is required, and no real employee data or credentials are included.

The current importer requires an explicit synthetic-data marker. Adapting it to real organizational identity data would require a documented lawful purpose, access control, minimization, retention and deletion rules, encryption, audit logging, regional review, and careful treatment of inferred security risk. Authentication, RBAC, CSRF protection, and rate limiting are also required before internet-facing deployment.
